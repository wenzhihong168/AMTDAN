# Contributing

AMTDAN is currently maintained as a research preview. Contributions should improve documentation, evaluation design, reproducibility, or the future package structure without introducing unpublished clinical data.

## Contribution areas

- Documentation and terminology corrections
- Evaluation protocols and metric definitions
- Reproducibility checklists and configuration design
- Privacy-safe dataset interfaces
- Tests for future public modules

## Research boundaries

- Do not commit patient-level data, identifiers, model checkpoints, or credentials.
- Keep unpublished numerical claims clearly labeled as preliminary.
- Separate implementation proposals from experimentally validated results.
- Use small, focused commits with a concise description of the scientific intent.

## Review checklist

1. Confirm that no sensitive or restricted material is included.
2. Verify that reported values are traceable to an approved manuscript artifact.
3. Keep figures publication-safe and provide meaningful alternative text.
4. Ensure new paths follow the repository layout documented in `README.md`.
